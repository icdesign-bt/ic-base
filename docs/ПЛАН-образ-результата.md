## Позиционирование

**База знаний 2.0** — единый источник корпоративных знаний ИЦ. Хранение файлов, поиск по смыслу, чат с ИИ по документам и материалы встреч — в одном месте.

Не забираем чужие продукты — **встраиваем наработки** S-044 / S-052 / S-045 в обновлённую S-011.

**Формула боли:** для сотрудников ИЦ (Аппарат / HR / продакты) быстро находить актуальную версию и смысл из документов и встреч → меньше копий в чатах, выше «нашёл с первого раза».

| Система | Вердикт | Роль в образе |
|---------|---------|---------------|
| S-011 База знаний | Развивать | Оболочка / точка входа |
| S-044 Умный поиск | Развивать | Поиск по смыслу |
| S-052 AI-хаб | Развивать | Чат / сценарии |
| S-045 Транскрибатор | Сопровождать → в образе to-be **развивать** | Встреча → знание |

## User stories

**Ценность**
1. Поиск по смыслу — «Инновационная столица» (февраль 2027), разные формулировки
2. ИИ-чат — «как завести инициативу» → инструкция / ЕДИ / презентация
3. Виджет встречи → транскрипт → саммари → карточка в БЗ

**Главная**
4. Recent documents  
5. История запросов в поиске  
6. Видимый ИИ-чат  
7. Саммари встречи + календарь + «Вас упоминали»  
8. Preview до скачивания/открытия  

**ACL**
9. Строгие доступы во всех поверхностях  
10. Переключатель роли в демо  

Только **to-be** UI. Intent + синонимы без живого LLM.

## UI и адаптив

Референсы: Google Drive / Я.Диск / GitHub / Bitrix24.

Desktop (≥1024): сайдбар + центр + glass-чат.  
Tablet (600–1023): компактная двухзонка, чат sheet.  
Phone (&lt;600): одна колонка, сайдбар drawer, чат full-screen/sheet.

**Must:** Apple HIG + Material adaptive layouts (safe areas, touch ≥44–48px, reflow).
