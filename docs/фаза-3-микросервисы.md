# Фаза 3 — микросервисы (поиск / чат / встречи / preview)

## Что сделано

- **Умный поиск + ACL:** intent-сценарии (Innovacapital / инициатива / ACL / знание из встречи), чипы на странице и в dropdown, карточки хитов со score / папкой / сниппетом, баннер «скрыто ACL».
- **ИИ-чат + ACL:** ответы с цитатами (в т.ч. Innovacapital), чипы подсказок, системная реплика при смене роли, текст про недоступные источники, клик → preview.
- **Встреча → карточка в БЗ:** пайплайн Транскрипт → Саммари → Карточка; для стендапа — preview + «Найти в поиске»; иначе CTA «Сохранить в БЗ» (мок).
- **Preview до скачивания:** различимый вид pdf / docx / pptx / xlsx / image / md|txt; подпись «предпросмотр · скачивание после»; кнопки — мок-алерты.

## Проверка

```bash
npm run dev
```

1. Чип «Инновационная столица» / близкая формулировка → одна выдача сценария.
2. Роль **Сотрудник** + «служебная записка аппарат» → пусто + баннер ACL; роль **Аппарат** → документ есть.
3. Чат: «как завести инициативу» → ответ + 3 источника → preview.
4. Встреча стендапа → карточка в БЗ → «Найти в поиске» находит её.
5. Preview: pdf (программа), docx (бриф), pptx (дек), image (схема), md (карточка встречи) — до «Скачать».
