## Тайминг

### 0:00–0:40 · Боль и тезис
- 21k+ файлов, поиск по имени/папкам, копии в чатах, ИИ-сервисы разрозненно.
- Цитата Стратегии (если нужно): «скачиваю десяток документов, чтобы понять, где тот самый».
- Тезис: **БЗ 2.0 = единая оболочка**, в которую встроены наработки S-044 / S-052 / S-045 — не забираем продукты.

### 0:40–1:30 · Главная = хаб (US 4–7)
- Показать: недавние файлы/папки, саммари встречи, «Вас упоминали», календарный контур встреч, видимый вход в ИИ-чат / ассистента.
- Одна фраза: «сотрудник не уходит в три URL».

### 1:30–3:00 · Поиск по смыслу (US 1)
1. Открыть умный поиск.
2. Чип **«Инновационная столица»** (или вручную близкую формулировку).
3. Показать выдачу сценария: релевантность, сниппет, папка.
4. Опционально: вторая формулировка из списка phrases — та же выдача.

### 3:00–4:20 · Preview (US 8)
1. Открыть превью pdf / pptx / docx / image **до** «Скачать».
2. Связка с ОС: «когда хранилище отвалилось — хотя бы понять документ; сейчас люди качают вслепую».

### 4:20–5:40 · ИИ-чат (US 2)
1. Чип / запрос **«как завести инициативу»**.
2. Ответ + 3 цитаты (инструкция / ЕДИ / шаблон питча) → клик в preview.
3. Акцент: ответ только по доступным документам.

### 5:40–6:40 · Встреча → карточка (US 3)
1. Виджет / раздел встреч → стендап.
2. Транскрипт → саммари → карточка в БЗ.
3. Чип **«Итоги стендапа»** в поиске — карточка находится.

### 6:40–7:40 · ACL (US 9–10)
1. Роль **Сотрудник** + чип **«ACL · служебная записка»** → пусто / баннер ACL.
2. Роль **Аппарат руководителя** → документ виден.
3. То же правило для чата / recent / preview.
