# User stories образа База знаний 2.0

**Аудит покрытия (8 нояб. 2026):** все US 1–10 закрыты в моковом прототипе (фазы 1–3). Демо-порядок — [фаза-4-демо-скрипт.md](./фаза-4-демо-скрипт.md). Post-образ идеи — [бэклог-после-прескрининга.md](./бэклог-после-прескрининга.md).

## Сценарии ценности

1. **Поиск по смыслу** — запрос вроде «нужна актуальная документация по Инновационной столице» (и близкие формулировки) → выдача с релевантностью, фрагментом, папкой, датой. Корпус: мероприятие **Инновационная столица (февраль 2027)**. ✅ в образе · подтверждено ОС Стратегия (поиск по содержимому / шум имён файлов)
2. **ИИ-чат с цитатами** — «как завести инициативу» → ответ + ссылки на пошаговую инструкцию, ЕДИ, презентацию. ✅
3. **Клик по виджету встречи** → транскрипт стендапа → саммари, решения, action items → карточка в БЗ, находится поиском и чатом. ✅ · ОС: разрыв «Мои совещания»↔БЗ усиливает ценность

## Главная и оболочка

4. На главной — **последние документы**, с которыми работал. ✅ · ОС: также просят частые папки (бэклог next)
5. В поле умного поиска — **последние запросы**. ✅ · ОС: «как в браузере»
6. На главной видно **окошко ИИ-чата**. ✅
7. На главной — **саммари последней встречи** + **календарь встреч** + блок **«Вас упоминали»** (контекст задачи). ✅
8. **Предпросмотр** документа до скачивания или открытия. ✅ · ОС: топ-боль («скачиваю восьмой раз», «пролистать слайды»)

## Доступы

9. БЗ 2.0 **строго учитывает доступы** во всех поверхностях (поиск, чат, recent, встречи, превью). ✅ · ОС: read/edit/hide папок, конф. проекты
10. **Переключатель роли** в демо: без доступа — нет в выдаче / «нет доступа»; с доступом — объект открывается. ✅

## Правила показа

- Только to-be UI (без колонки «как сейчас»).
- Многоформулировочные моки: intent + синонимы + fuzzy.
- Тимофею устно: это моковый образ результата.
- **Адаптив сразу:** layout и навигация корректны на phone / tablet / desktop (Apple HIG + Material adaptive layouts), не «десктоп-only».
