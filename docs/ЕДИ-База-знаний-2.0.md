## Шаг 1. Идея

Предлагается **обновить Базу знаний** так, чтобы сотрудники ИЦ находили документы и смысл из встреч **в одном месте**, с поиском по смыслу, ИИ-чатом и встроенным транскрибатором — без прыжков между отдельными ИИ-сервисами.

**Проблема:** при 21k+ файлах и ~320+ сотрудниках сложно быстро найти актуальную версию; знания из встреч и ИИ-поиска живут отдельно; доступы и отсутствие preview — явная боль (ОС Стратегия: «скачиваю десяток», «нужен предпросмотр»).

**Где:** корпоративная База знаний (S-011) + связка с наработками S-044 / S-052 / S-045.

**Почему сейчас:** вердикт портфеля «развивать»; ИИ-наработки уже есть, но узкий охват / разрозненные URL; перезапуск БЗ даёт массовую точку входа.

## Шаг 3. Самопроверка

### 3.1 Как решают сейчас

Поиск по папкам/именам в icknowledge (часто — обход нескольких папок управления), скачивание пачки файлов «чтобы понять», пересылки в мессенджерах. Умный поиск (ragu) — отдельно и для узкой аудитории. Транскрипты / «Мои совещания» — отдельно и слабо связаны с БЗ. AI-хаб — пока контур больших данных.

**Неудобно:** долго, много копий, нет единого смысла «где живёт знание», слабые/непрозрачные доступы, нет нормального preview.

### 3.2 Кого затрагивает

| Кто | Как |
|-----|-----|
| Аппарат / Стратегия / HR / сотрудники | Ищут документы ежедневно |
| Продакты / носители идей | Нужны инструкции RnD, ЕДИ, презентации |
| Овнеры S-044/S-045/S-052 | Их наработки встраиваются в БЗ (не забираются) |
| Админы папок управлений | Раздают права, следят за актуальными версиями |

### 3.3 Что уже есть

| Что проверили | Что нашли | Почему недостаточно | Опереться |
|---------------|-----------|---------------------|-----------|
| S-011 База знаний | Хранение и базовый поиск, 21k+ файлов | Нет ИИ-слоя, боли findability, preview, ACL | да — оболочка |
| S-044 Умный поиск | Векторный поиск по смыслу | Узкий доступ, отдельный URL | да — микросервис |
| S-052 AI-хаб | Чат + каталог сценариев | Пока только БД | да — сценарии/чат |
| S-045 Транскрибатор | Запись → саммари | Не связан с БЗ как знание; в портфеле «сопровождать» | да — встроить, аргумент развивать |

**Вывод:** отдельных сервисов мало для массового сценария «нашёл и сохранил знание в одном месте».

### 3.4 Польза

| Для кого | Что станет лучше |
|----------|------------------|
| Сотрудники | Быстрее находят; меньше копий и «слепых» скачиваний; ответы с цитатами |
| Управление автора / дизайн | БЗ снова развиваемый продукт с ясным образом |
| ИЦ | Единая точка входа к ИИ-наработкам + контроль доступов |
