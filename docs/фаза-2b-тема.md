# Фаза 2b — фон design-crm + светлая/тёмная тема

## Что сделано

- Ambient-фон как в design-crm glass: фиолетово-сине-розовые blobs + градиент (`body::before` / `::after`)
- Скин `data-skin="glass"` всегда (прототип = glass)
- Тема: **Системная / Светлая / Тёмная** — переключатель внизу сайдбара над «Роль»
- Сохранение в `localStorage` (`ic-base-theme`)
- Dark-ветка glass-токенов + замена hardcoded `#fff` / light-only цветов на `--app-*` токены
- ic-kit компоненты переключаются через `document.documentElement.dataset.theme`

## Файлы

- `src/utils/theme.ts` — init / apply / storage
- `src/styles/skin-glass.css` — ambient + glass light/dark tokens
- `src/components/layout/ThemeSwitcher.tsx`
- `src/styles/app.css`, `src/styles/shell.css` — theme-aware surfaces

## Проверка

```bash
npm run dev
```

1. На светлой теме виден тот же «сочный» фон, что в design-crm.
2. Внизу сайдбара: Системная / Светлая / Тёмная → фон и панели меняются.
3. Glass-панели остаются полупрозрачными поверх blobs в обеих темах.
4. После reload выбранная тема сохраняется.
