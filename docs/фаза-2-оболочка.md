# Фаза 2 — оболочка UI

## Что сделано

- Layout: сайдбар + центр + glass ИИ-чат (desktop)
- Adaptive: tablet — drawer-меню + floating chat; phone — stacked header, chat sheet снизу, preview sheet
- Главная: recent, саммари встречи, «Вас упоминали», календарь
- Поиск с историей запросов → `/search`
- Папки, встречи, карточка встречи (транскрипт / решения / action items)
- Preview drawer до «Скачать» / «Открыть»
- Переключатель роли (ACL) — **левый нижний угол** сайдбара
- Кнопка ИИ-чата — **FAB справа внизу**
- Glass как в design-crm (`backdrop-filter` + полупрозрачный фон) на шапке / сайдбаре / main / чате
- Moscow Sans на body и дереве папок (`--font-family-sans` из ic-kit)
- Дальше: [фаза 2b — фон + тема](./фаза-2b-тема.md)

## Проверка

```bash
npm run dev
```

1. Desktop ≥1024: три колонки, чат справа.
2. Сузить до tablet: меню-гамбургер, чат float.
3. Phone: поиск на второй ряд шапки, чат снизу.
4. Клик по документу → preview; смена роли → папки/документы меняются.
