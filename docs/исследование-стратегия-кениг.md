## 1. Управление стратегией — подтверждённые боли

| Тема | Что сказали | Цитата / суть | Связь с US / образом |
|------|-------------|---------------|----------------------|
| Preview | При падении хранилища нельзя даже посмотреть файл; скачивают «вслепую» по 8+ раз | «было бы идеально, если бы предпросмотр»; «пролистать слайды» | **US 8** — Must, в демо |
| Навигация по папкам | Ищут проект в 3 папках консалтинга (стратегическая / операционная / хокки), год известен, проект — нет | «прохожусь по всем… скачиваю десяток» | US 1 + оболочка папок |
| Умный поиск по содержимому | Имена файлов = названия проектов, не отражают контент; глобальный поиск шумит картинками | «смотрел не только названия… но и материалы внутри»; фильтр формата | **US 1** — Must |
| Recent / частые папки | Каждый раз заново лезут в одни и те же папки | «недавно просмотренные» / «часто используемые» сверху | **US 4** + Could «избранное» |
| История запросов | Хотят поиск «как в браузере» | «раскрывающий поиск… частые запросы» | **US 5** |
| Встречи ↔ БЗ | «Мои совещания» (ЦОД) не связаны с БЗ; поиск там видит только свои файлы | запрос: календарь + файлы из БЗ у встречи, share без входа в БЗ | **US 3, 7** (часть); внешний share — Could / post |
| ACL / конфиденциальность | Конф. и спецпроекты не выкладывают; смешаны внутренние отчёты и общие инструкции | права на папку (read/edit/hide); управление / персонально / роль админа | **US 9–10** |
| Версии | Грузят только финал; удаляют старый → заливают новый; история в чате/треде | «нашла файл и заменила» одним запросом — nice | Won’t образа; backlog |
| Саммари / ЕДО | Запрос Ильи: протоколы, поручения, отчёты — авто по проекту | без ИИ «вряд ли» | **US 3** как направление |
| Org-wiki / люди | База о сотрудниках: отпуска, ДР, проекты, «к кому идти» | out of box, ускорит работу | Could / соседний продукт |
| Уведомления | Колокольчик на папку / избранное при обновлении | «Катя Фатеева обновляет — не вижу» | Could |
| Tree expand | Стрелка без проваливания в папку | UX оболочки | Should UX |

**Приоритет респондентов:** поиск и preview в первую очередь; ACL и recent — следом; wiki/уведомления — nice.
