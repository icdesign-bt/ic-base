# База знаний 2.0 — рамка образа результата

**Этап RnD:** подготовка к шагу 4 (пре-скрининг у Тимофея Пенского)  
**Репозиторий:** `/Users/kurylev/AI/ic-base`  
**Формат сдачи:** кликабельный веб-прототип на моках + питч + ЕДИ

## Позиционирование

**База знаний 2.0** — единый источник корпоративных знаний ИЦ. Сотрудник не прыгает между отдельными сервисами: хранение файлов, поиск по смыслу, чат с ИИ по документам и материалы встреч — всё в одном месте.

Не забираем чужие продукты — **встраиваем наработки** Умного поиска (S-044), AI-хаба (S-052) и Транскрибатора (S-045) в обновлённую Базу знаний (S-011).

## Формула боли

> Для сотрудников ИЦ (фокус: Аппарат руководителя / HR / продакты) закрыть задачу «быстро найти актуальную версию и смысл из документов и встреч», чтобы сократить поиск по чатам/копиям и повысить «нашёл с первого раза».

## MoSCoW среза демо (пре-скрининг)

### Must
- Главная: recent documents, поиск с историей запросов, glass ИИ-чат, саммари встречи + упоминания + календарь
- Поиск по смыслу (intent + синонимы), сценарий «Инновационная столица»
