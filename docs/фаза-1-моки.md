# Фаза 1 — мок-данные (справка)

## Структура

| Путь | Содержание |
|------|------------|
| `src/types/knowledge.ts` | Модель: Document, Folder, Meeting, ACL, Intent… |
| `src/mocks/` | Папки, документы, встречи, recent, роли |
| `src/scenarios/intents.ts` | Кластеры формулировок + `matchIntent` |
| `src/lib/acl.ts` | `canView` |
| `src/lib/corpus.ts` | Выдачи с учётом роли + поиск |

## Как проверить

```bash
npm run dev
```

1. Переключи роль **Сотрудник** → «служебная записка аппарат» даёт пусто / скрыто.
2. Роль **Аппарат** → та же фраза находит чувствительный документ.
3. Чипы «Инновационная столица» / «как завести инициативу» → intent + выдача / ответ чата.
4. Блок recent / саммари / «Вас упоминали» заполнены.
