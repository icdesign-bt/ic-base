# База знаний 2.0 — образ результата

Моковый веб-прототип для пре-скрининга RnD (шаг 4) у Тимофея Пенского.

## Демо

Живой мок: **[https://icdesign-bt.github.io/ic-base/](https://icdesign-bt.github.io/ic-base/)**

## Запуск

```bash
npm install
npm run dev
```

Откроется на **https://localhost:5175/** (self-signed; в браузере — «Продолжить»).

С телефона в той же Wi‑Fi: `https://<IP-Mac>:5175/` (IP: `ipconfig getifaddr en0`). HTTPS нужен для голосового ввода в Safari.
